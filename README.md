# JavaFX Calculator

A desktop calculator application built with Java and JavaFX that performs basic arithmetic operations.

## Key Features
- Clean, responsive graphical user interface (GUI) using `AnchorPane` for layout.
- Performs addition, subtraction, multiplication, and division on decimal numbers.
- **Error Handling:** Uses `try-catch` blocks to catch `NumberFormatException` and display a friendly "Type Number!" warning if the user enters non-numeric characters.

## What I Practiced
- **JavaFX UI:** Building scenes, styling with CSS (`-fx-background-color`), and positioning UI elements.
- **Event-Driven Programming:** Using Lambda expressions (`->`) to handle button clicks.
- **Data Parsing & Exception Handling:** Safely converting text inputs to `Double` and handling invalid inputs gracefully.

## How to Run
1. Open the project in NetBeans or VS Code.
2. Run `App.java`.
3. Enter two numbers and click the operation buttons (+, -, *, /).

## Tech Stack
- Java, JavaFX
